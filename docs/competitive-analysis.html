02

直接竞品与硬伤

head-to-head

Firewalla 最强竞品

插路由的网络行为分析盒子 + VPN + 家长控制。云端行为分析。

缺:签名 / 链上存证 / 物理输出 / 解释;告警只进手机 App。

Bitdefender BOX 在售

家庭网络防护中枢 + 订阅。Box 2 已停产但仍支持。

缺:云依赖,无存证、无物理告警。

CUJO AI C 端已停产

智能防火墙,包元数据传云分析。2021 起转 B2B 卖给 ISP。

缺:元数据上云的隐私争议;已退出消费级。

Fing / Fingbox 在售

网络扫描、设备发现、陌生设备告警。

缺:只做「发现设备」,无深度检测 / 无存证。

Gryphon 在售

带安全的路由器 + AI 威胁防护 + 家长控制。

缺:路由器形态、云依赖,无存证 / 物理输出。

企业 IoT 安全 另一赛道

Armis · Palo Alto IoT · Ordr。面向企业 / 园区。

缺:重、贵、要部署;非家用、无物理在场感。
